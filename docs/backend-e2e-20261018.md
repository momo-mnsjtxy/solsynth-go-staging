## 运行与隔离

```bash
PG_BIN=/path/to/postgresql16/bin GO_BIN=/path/to/go \
  PG_TEST_ROOT=/tmp/solian-e2e \
  bash scripts/integration-postgres.sh --local-disposable --backend-e2e --local-tcp
```

命令自行创建临时集群、随机 loopback 端口与合成 SCRAM 密码，不接受现成的数据库目标。本地模式拒绝 CI/GitHub 标识；保留私有目录、marker、精确 DSN、干净 Git HEAD、schema 指纹和空模板检查。Go 与 Python 在本地 TCP 首次操作前只读验证 `data_directory` 严格等于当前 `run/data`，避免将已有本机数据库误认为临时目标。CI 默认的私有 Unix socket 运行方式和完整两组用例清单保留。

本执行环境禁止 Unix socket，仅有 namespace UID 0 且没有 Linux capabilities；标准 Ubuntu PostgreSQL 二进制通过透明 UID 映射包装运行，包装源码已保留为 [namespace_uid.c.txt](validation/backend-e2e-20261018/namespace_uid.c.txt)。数据库和应用二进制没有打补丁。这是本次运行环境的适配条件，不是生产部署建议。密码、私钥和数据库数据目录没有进入证据目录。

旧来源指纹没有被更新成新文件：原审阅清单原样保留，本次变动另列于 [本地模式审阅记录](local-disposable-pg-review.json)，同时校验历史字节与当前文件。历史 Go 文件以 `.go.txt` 保存，避免被 Go 编译成活动代码。分组草稿仍会标出相对历史清单的依赖变化，不自动宣称完整 CI 已通过。
