# Public board widget discovery

GET /api/apps/board and the host /develop/apps/board alias now return the authored app/widget DTO array from canonical PostgreSQL state. Defaults are take=20, offset=0, optional slug. A nonblank slug selects one app and ignores pagination, matching the retained controller. Unknown slugs and no eligible widgets return an empty array; no total header is invented. Widget slugs use publisher_name.app_slug.widget_key, as documented in the retained authored board guide.
