# Provenance

This package implements a bounded post interaction domain from AGPL-licensed
DysonNetwork controllers/services and authored AGPL Solian callers. Exact pinned
URLs, git blobs, byte counts and SHA-256 hashes are in `source/manifest.json`;
`TestPinnedAuthoredEvidence` verifies them. Existing retained controller and
permission-registry files are referenced in place. Source licenses are retained
in `source/DYSON-LICENSE.txt` and `source/SOLIAN-LICENSE.txt`.

Behavior, canonical schema composition, authority requirements, intentional
stronger privacy/atomicity choices and unsupported contracts are described in
`docs/post-interactions-continuation.md` at the repository root. No excluded
Shared/NeTo/Spec implementation, generated bindings or protocol schemas are used.
